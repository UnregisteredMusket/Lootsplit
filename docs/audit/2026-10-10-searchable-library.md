# Searchable imported data and Library entries — October 10, 2026

The owner requested searchable dropdowns for locations, NPCs, monsters and other imported data, plus direct record links to their Library entries. The supplied screenshots showed a long native location menu and map NPC links that opened the general NPC screen.

## Implemented behavior and preservation

- Shared search pickers retain the original option IDs, commands, defaults, disabled choices and native form validity. Search ignores accents/case and accepts multiple words; keyboard arrows/Enter, Escape, touch selection, no-result messages and additional result batches remain available. Options beyond the first 60 can be found by search or Show more. Menus work inside the native fullscreen map/editor dialog and existing import dialogs.
- Data pickers cover map and location assignment, NPC/controller selection, imported monster and pack selection, catalog/filter choices, imported names/books, shop setup and stock filters, property location/template/material/inventory/manager/import mappings, trading participants and encounter record/loot choices. Existing free-text searches, complete registers, imports and management controls remain available.
- Library indexes existing campaign records and imported references, without copying or changing them: locations, NPCs, authorized characters, shops/black markets, properties, maps/markers, source monsters/items/NPCs/locations/shops/references, catalog goods/services, names and property templates/materials. Its search covers names, descriptions, hierarchy, source metadata and type; results have type filtering and complete pagination.
- A Library entry displays saved description/image, relevant fields, monster statistics, source book/page, attribution, warnings and related-entry links. IDs include record type and source pack/revision, so repeated names or entry IDs cannot open a different record. URL keys have a non-JSON prefix so router search parsing retains their identity.
- Map icons, detail links and register rows open the actual NPC/location/shop/property/marker Library entry. NPC titles and imported creature/reference links also open their Library entries. The NPC interaction action opens the specific NPC, and saved-map actions select the specific map. Existing interaction/configuration/shop/property screens are preserved.
- Library reads the existing permission-projected campaign. Player entries require the existing NPC presence, shop visibility, character assignment and property access rules. Source packs and device catalog/lexicon remain DM-only; private maps/markers are omitted. An unavailable direct URL shows a generic unavailable entry message. Saved edits update the index; no separate stale copy, room write, financial mutation or new migration is introduced. Private PDFs remain device-local.
- Long location menus build hierarchy labels once using one ID lookup map before sorting, avoiding a new lookup-map allocation on each comparison. A local 508-row import initially exceeded the existing five-second completion assertion under concurrent checks; the existing assertion passed after this adjustment. This is not a measured production speed claim or grounds for a performance-reference reset.
