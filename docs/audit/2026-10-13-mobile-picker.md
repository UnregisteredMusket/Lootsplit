## Reproduction and repair

Selecting a preset opens the existing TemplateWorkshop within the same dialog. The listing's React draft remains intact; save returns the schema-validated template key and accurate committed/pending feedback, restores picker focus/scroll context, and requires a separate listing save. Cancelling asks before discarding the template and retains the listing. Busy operations block closure. UI-only `preset:` values cannot enter the persisted template key. No nested forms or second approval system are introduced.

The shared SearchSelect popover was outside the Radix property's dialog scroll-lock boundary. Native CDP touch events against unchanged main reproduce blocked touchmove events and scrollTop0 despite overflow. With modal containment and the dialog-aware portal, touch moves are allowed and the option list scrolls; parent dialog/page remain stationary, including at the list boundary. The menu caps itself to the visual viewport and collision space, with a flexible list and fixed search/status surfaces. Keyboard arrows scroll only that list; open/close focus uses preventScroll. Existing Unicode/all-term search, disabled choices, native required validation, original values, 60-result paging and themes remain.
